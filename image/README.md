# 로컬 사진 파일

- 메인: `main/main.jpg`
- 선수: `players/년도/배번.jpg` (예: `players/2026/7.jpg`)

메인 JPG는 이 폴더에 직접 복사하세요. 선수 JPG는 직접 복사하거나 `node local-server.js`로 열린 관리자 화면에서 등록할 수 있습니다. 같은 이름의 파일을 다시 올리면 기존 사진을 덮어씁니다. GitHub Pages에 반영하려면 이 폴더의 JPG도 저장소에 커밋하고 게시해야 합니다. 이 폴더의 파일은 Firebase Storage를 사용하지 않습니다. 갤러리 사진은 기존처럼 Storage를 사용합니다.
